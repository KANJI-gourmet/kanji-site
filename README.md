# KANJI

KANJI public website.

- Static site: GitHub Pages
- Authentication / member data / favorites: Supabase
- KANJIN numbers start from No.0 and increment sequentially.
- Analytics: GA4 measurement ID is intentionally left unset until the owner creates the GA4 property.

Never commit Supabase secret/service-role keys or personal data to this repository. The publishable browser key in `config.js` is intended for client-side use together with RLS.
